# Study Planner

参考書のバーコードを読み取って勉強時間を記録し、教科・教材・テストを管理できるスタディプランナーです。Claude の API キーを入れると、記録したデータをもとに学習計画や振り返りを AI に相談できます。

`index.html` 1ファイルで動作し、サーバーやビルドは不要です。

## 主な機能

- バーコード読み取り：参考書の ISBN（978…）を読み取ると、登録済みの本ならそのまま計測開始、未登録なら書籍情報（openBD / Google Books）を自動取得して登録
- 勉強時間の記録：開始・一時停止・終了のタイマー（リロードしても継続）、手動入力、記録の削除
- 教科・教材管理：教科の追加・色分け、教材を教科ごとに分類、累計時間の表示
- テスト管理：これから／過去のテスト、教科別の得点・満点・目標点、残り日数、得点率の推移グラフ
- カレンダー：月ごとにテスト予定と日々の学習時間を表示、日付からテストを追加
- 小テスト：教科・教材・範囲・難易度を指定してAIが4択問題を作成、マークして採点、解説と「くわしく解説」、履歴と解き直し
- 解説：わからない問題や用語をAIが解説
- ダッシュボード：今日／直近7日の学習時間、1日の目標達成率、直近14日の教科別グラフ
- AI（Claude）：APIキーとモデルを設定し、学習計画の作成・テスト対策・振り返りを相談
- データのエクスポート／インポート（JSON）、ライト／ダーク表示

## 使い方

カメラは HTTPS（または localhost）でのみ使えます。おすすめは GitHub Pages での公開です。

1. リポジトリの Settings → Pages で、ブランチと `/ (root)` を選んで公開
2. 表示された URL をスマホで開く（ホーム画面に追加すると便利です）

ローカルで試す場合は、次のコマンドで起動して `http://localhost:8000` を開きます。

```bash
python3 -m http.server 8000
```

バーコードは、対応ブラウザ（Android の Chrome など）では標準の BarcodeDetector を使い、非対応ブラウザ（iPhone の Safari など）では [html5-qrcode](https://github.com/mebjas/html5-qrcode) を自動で読み込みます。書籍の裏表紙には2段のバーコードがあるので、上段（978から始まる方）を読み取ってください。ISBN は手入力もできます。

## AI（Claude）の設定

1. [Anthropic Console](https://console.anthropic.com/) で API キーを発行
2. 設定タブで API キーを入力し、モデル（標準は `claude-sonnet-5-5`）を選んで保存
3. 「接続テスト」で確認
4. 「AIの回答の長さ」で短め（既定）／標準／長めを選択。短いほど API のトークンを節約できます

API キーはブラウザの localStorage にのみ保存され、ブラウザから Anthropic の API（`api.anthropic.com`）へ直接送信されます。共用端末では使用後に「キーを削除」してください。API の利用料金はキーの持ち主に発生します。

## データの保存

すべてのデータはブラウザの localStorage に保存され、外部サーバーには送信されません（AI 機能で「学習データを送る」をオンにしたときは、その要約が Anthropic に送られます）。ブラウザのデータ削除や端末の変更に備えて、設定タブからときどきエクスポートしてください。
